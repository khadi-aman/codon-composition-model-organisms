# Methodology and provenance

## Reported by the dissertation
- Orthologous sequences were obtained using NCBI/Ensembl resources.
- Codon profiles and RSCU values were compared.
- Correlations between codon profiles were tabulated.
- GC3% and AT3% were compared.
- CAIcal is cited for RSCU/CAI-related calculations, and Excel was used to organize comparisons.

## What this repository adds
- Export of embedded RSCU chart values to a long-form CSV.
- Export of dissertation correlation tables to CSV matrices.
- Three descriptive figures built from those extracted values.

## Not included because supporting numeric data were not found in the supplied DOCX
- CAI score table.
- Full numerical GC3%/AT3% dataset.
- A clearly documented study-specific UPGMA tree or its distance matrix.
- Raw FASTA sequences and original calculation workbooks.

Do not interpret the descriptive plots as an independent validation of the thesis's biological conclusions.
