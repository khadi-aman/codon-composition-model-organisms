# Results

Numerical tables extracted from the dissertation's embedded Word chart data and correlation tables.

- `rscu_values_long.csv`: gene, organism, codon and RSCU value.
- `correlation_<gene>.csv`: symmetric matrix assembled from the triangular correlation table in the thesis.
- `correlation_summary_by_gene.csv`: minimum, maximum and mean of available off-diagonal pairwise correlations for each gene.

The matrices preserve values as presented in the thesis. They have not been independently recomputed from raw sequences.
